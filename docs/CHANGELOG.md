# 변경 기록

## 0.1.6

- 입을 약 0.3초 벌리면 재생/일시정지를 위한 영상 중앙 탭을 한 번 전송. 입을 닫아야 다시 입력하며 계속 벌린 상태에서 반복하지 않음.
- 기존 얼굴 모델의 입술 안쪽 간격/입 너비로 입 벌림 측정. 크기·회전에 대응하는 비율을 사용하며 새 모델이나 권한을 추가하지 않음.
- 입 동작 인식 중 눈 넘김 억제, 입 닫음·양쪽 눈 뜸 후 눈 입력 재개. 모든 명령에 공유 1.8초 간격을 적용하고 대기 중 명령을 지연 실행하지 않음.
- 기본 켜짐의 입 제어 설정과 단독 입 연습 화면 추가. 시선 보정 없이 입 연습 가능하며 연습·관찰 모드에서는 실제 탭을 보내지 않음.
- 다음·이전·재생/멈춤 연습 횟수 구분, 설명·접근성 안내 갱신. 화면 제한·최종 재확인·카메라 해제 동작 유지.
- 탭 완료와 실제 영상의 재생 상태는 구분하며 실제 영상 상태를 읽거나 저장하지 않음. 두 앱의 재생/일시정지와 입 인식 편의성은 실기기 확인 필요.

## 0.1.5

- 윙크 입력을 본인의 오른쪽 눈 → 다음 영상, 왼쪽 눈 → 이전 영상으로 구분. 즉시 입력·양쪽 눈 뜸 후 재입력·1.8초 간격 유지.
- MediaPipe의 신체 기준 좌우 눈과 카메라 측정 필드를 일치시킴. 표시용 미리보기 미러 효과는 입력 방향과 분리.
- 이전 명령은 기존 다음 스와이프의 반대 방향으로 전송. 세 시선 방식은 기존처럼 다음 명령만 사용.
- 정식 Instagram 앱의 알려진 전체 화면 릴스 재생기 ID와 크기를 확인해 지원. YouTube 쇼츠 제한은 유지하고, 두 앱 모두 전송 직전 재확인. 입력란 포커스가 있으면 전송하지 않음.
- 인스타그램 열기 버튼, 연습의 다음/이전 횟수와 방향 안내 추가. 추적을 켠 상태로 두 앱 전환 가능.
- 확대된 앱/동작 범위에 맞춰 접근성 설명과 앱 내 안내 갱신. 이번 범위 안내는 기존 사용자에게도 한 번 더 표시.
- 실제 다음 넘김에 대한 사용자 만족 피드백은 0.1.4에서 확인. 0.1.5 좌우 구분·이전 넘김·Instagram 호환성은 별도 실기기 확인 필요.

## 0.1.4

- 사용자 요청대로 윙크를 단순화: 화면에 표시하는 ‘한쪽 눈 감음’ (`FaceQuality.ONE_CLOSED`)을 그대로 사용하여 즉시 한 번 입력.
- 눈 뜸 학습, 평소 대비 감음 비율, 0.4초 유지, 다시 뜬 후 명령 조건 제거. 별도 눈 열림 비율 표시도 제거.
- 계속 감기·감는 눈 바꾸기·얼굴 유실로 반복 입력하지 않음. 양쪽 눈 뜸으로 다음 입력을 준비하고 기존 1.8초 간격 유지.
- 안내 문구를 새 동작에 맞게 수정. 깜빡임 중 잠깐 한쪽 눈 감음으로 측정된 경우도 즉시 입력하는 규칙에 포함.
- 새 즉시 입력/반복 방지/화면 제한 동작에 맞춰 윙크 테스트 교체. 나머지 시선 방식과 YouTube 화면 제한 유지.

## 0.1.3

- 사용자 피드백: 미리보기에 ‘한쪽 눈 감음’은 표시되지만 윙크 연습 성공 횟수가 오르지 않음.
- 눈 감음 표시보다 엄격했던 윙크 임계값을 완화하고, 준비 중 익힌 양쪽 눈의 열림 비율 및 두 눈의 차이를 함께 사용. 반대쪽 눈의 가벼운 찡그림을 허용.
- 눈을 감고 다시 뜨는 중간 상태에서 즉시 취소하던 문제 수정. 잠깐의 중간 상태는 유지하되, 확인된 눈 감음 구간만 누적하여 짧은 깜빡임이 긴 윙크로 바뀌지 않도록 제한.
- 준비 완료, 눈 감음 확인, 다시 뜸 확인, 실패 이유, 다음 입력 대기 시간을 표시. 뜬 눈 대비 두 눈 열림 비율 표시 및 성공 문구 약 1.2초 유지.
- 실제 기기 영상 대신 합성 측정값으로 네 가지 기존 실패를 재현하고 수정 후 회귀 검사. 실기기에서 문제가 해결됐는지와 오작동률은 추가 확인 필요.

## 0.1.2

- 한쪽 눈 윙크 모드: 시선 위치 보정 없이 양쪽 눈 뜸을 익힌 뒤 한쪽 눈을 약 0.4초 감았다 뜰 때 명령. 양쪽 눈 깜빡임, 한 프레임의 비대칭 깜빡임, 긴 눈 감음, 머리 움직임을 제외.
- 오른쪽 보기 → 중앙 모드: 중앙/오른쪽 보정 후 오른쪽 응시와 중앙 복귀를 확인해 한 번 명령.
- 기존 아래→위, 위쪽 응시 모드 유지. 네 입력 방식별 보정과 비교 결과 분리.
- 전면 카메라 미리보기와 홍채 표시, 얼굴·눈 상태 추가. 미리보기만 확인하는 모드와 보정/연습 내 작은 미리보기 제공.
- 카메라 프레임을 저장하지 않고 UI에 보이는 동안만 미리보기 생성. 오래된 프레임, 화면 이탈, 카메라 종료 시 프레임 해제.
- 20회 입력 자가 테스트와 5분 관찰 모드 추가. 관찰은 실제 스와이프를 보내지 않고 감지 횟수·얼굴 확인 비율을 집계. 쇼츠 이외 화면과 카메라 정지 시간은 관찰 시간에서 제외.
- 보정 화면 배치 변경으로 예전 시선 보정은 다시 필요. 기존 앱과 같은 개발 키로 업데이트 설치 가능.

윙크·시선 분류의 실제 인식률과 미리보기 화면 배치는 실기기 검증이 필요합니다. 비교 기록의 감지 횟수는 정답이 확인된 정확도 수치가 아닙니다.

## 0.1.1

- 아래쪽을 잠깐 바라본 뒤 위쪽으로 빠르게 눈을 이동하면 한 번 넘기는 모드 추가. 기존 응시 모드도 선택 가능.
- 새 모드는 아래쪽/위쪽 2점 보정, 기존 모드는 중앙/위쪽 2점 보정. 프로필은 방식별로 분리.
- 시선 특징 추출을 눈꺼풀 중심 기준에서 눈 양 끝점 기준으로 변경. 눈꺼풀이 홍채와 함께 움직일 때 신호가 줄어드는 수학적 문제를 방지.
- 보정/연습의 점 위치를 동일하게 유지하고 안내 영역과 분리하여 아래쪽 점이 버튼에 가려지지 않게 배치.
- ‘인식 성공 N회’는 보정 후 연습 단계에 나타남. 보정 실패 메시지에 ‘보정 미완료’를 명시하고 신호 차이 부족/측정값 겹침을 구분.
- 시선 계산 방식이 달라져 예전 보정은 재사용하지 않음. 기존 개발 키를 유지하여 앱 위에 업데이트 설치 가능.

이 변경은 사용자 실기기의 0.1.0 보정 실패 피드백에 따른 개선입니다. 0.1.1 실기기 인식률과 실제 쇼츠 전환은 별도 확인이 필요합니다.
