입 벌리기 재생/일시정지를 추가했습니다. 입술 안쪽 간격/입 너비를 계산해 약 0.3초 열린 입을 감지하고, 입을 닫은 뒤 다시 입력합니다. 기존 윙크의 즉시 다음/이전 입력은 유지했습니다.

실행 명령: `scripts/build.ps1 -Tasks @('testDebugUnitTest','lintDebug','assembleDebug','--offline')`

입 너비 정규화·회전·좌우 입술 이동·유효하지 않은 좌표, 짧은 입 벌림 거부, 계속 벌림에서 한 번 입력, 입 닫음 재준비, 얼굴 유실/분석 간격/중복 측정/화면 이탈을 합성 좌표와 측정값으로 확인했습니다. 눈·입 동시 입력의 입 우선 처리, 입 입력 뒤 계속 감고 있는 눈의 지연 넘김 방지, 공유 1.8초 간격과 대기 중 입력을 지연 실행하지 않는 것도 확인했습니다.

입 단독 연습은 시선 보정을 요구하지 않고 실제 제스처를 보내지 않는 분기로 연결했으며, 관찰 모드도 명령 종류와 관계없이 실제 제스처를 보내지 않는 기존 분기를 사용합니다. 영상 중앙 한 점의 80ms 탭은 Android StrokeDescription의 정지 터치 방식입니다. 완료 콜백은 영상의 실제 재생 상태를 확인하지 않습니다.

새 연습 문구에서 발생한 번역용 문자열 경고는 리소스 문자열로 옮겨 해결한 뒤 전체 빌드/검사를 다시 통과했습니다. 남은 11개 경고는 기존 버전 고정/세로 화면 관련 경고입니다.

실제 기기에서 입 벌림 감도, 대화/하품 중 감지, 연습 화면 배치, 체크박스의 실행 중 변경, 두 앱의 멈춤·재생 전환과 영상이 멈춘 뒤 추적 유지 여부는 아직 확인하지 못했습니다. 기존 눈 인식과 좌우 구분을 포함해 실제 휴대폰 테스트가 필요합니다.

개발 PC에서는 0.1.5를 휴대폰에 설치/실행하지 않았습니다. 실제 좌우 눈 매핑, YouTube 이전 영상, Instagram 릴스 감지·다음·이전, 일반 피드/댓글/메시지/스토리에서의 동작, 새 안내와 UI 표시 위치는 아직 실기기 확인이 필요합니다. 사용한 외부 식별 자료와 한계는 README에 링크했습니다.

Lint 경고는 고정한 라이브러리/Gradle 버전의 업데이트 안내 9개와 MVP의 세로 방향 고정 관련 2개입니다. 검사 오류를 숨기는 baseline이나 오류 무시는 사용하지 않았습니다.

단위 테스트는 측정 수치를 입력한 로직 검증입니다. 실제 카메라 영상에서 같은 인식률이 나온다는 뜻은 아닙니다. 서명/정렬 검사도 실제 기기에서의 설치·실행 검증을 대체하지 않습니다.

## 아직 실행하지 않은 실기기 검증

개발 PC에 연결된 Android 기기가 없습니다. 사용자의 0.1.0 설치/보정 실패, 0.1.2의 눈 감음 표시/윙크 누락, 0.1.4 즉시 다음 넘김의 긍정적 피드백을 받았습니다. 각 버전의 실제 인식률과 아래 항목 전체를 체계적으로 확인한 것은 아닙니다.

- 앱 설치/첫 실행과 실제 기기의 화면 배치
- 전면 카메라의 홍채 특징점 안정성과 2점 보정 성공률
- 안경/조명/머리 움직임에 따른 오작동률
- 설치된 YouTube 버전에서 전체 화면 쇼츠 ID가 노출되는지
- 실제 다음 쇼츠 전환과 한 번 응시했을 때 한 번만 넘어가는지
- YouTube를 보고 있는 동안 카메라 포그라운드 서비스가 유지되는지
- 알림에서 일시정지/종료, 화면 끄기, 접근성 해제 시 카메라 해제
- 10분 이상 사용 시 배터리/발열

## 실기기 확인 순서

입 기능 확인: 0.1.6을 업데이트 설치하고 ‘입 벌리기 연습’에서 약 0.3초 벌림 → 1회 인식, 계속 벌림 → 추가 없음, 닫았다 다시 벌림 → 다음 인식을 확인합니다. 실제 쇼츠와 릴스에서 손으로 중앙을 한 번 탭해 멈춤/재생되는지 확인한 뒤 입 명령을 시험합니다. 눈/입 입력 사이에는 약 2초 간격을 두고, 입을 벌리며 한쪽 눈을 감아도 다음/이전 넘김이 겹치지 않는지 확인합니다. 홈 체크를 끄면 눈 입력만 동작하는지도 확인합니다.

0. 0.1.5를 업데이트 설치한 뒤 ‘한쪽 눈 윙크 → 윙크 연습하기’에서 오른쪽 눈 → 다음 횟수, 왼쪽 눈 → 이전 횟수 증가를 확인합니다. 계속 감고 있어도 한 번만 입력되는지 확인하고, 양쪽 눈을 뜬 뒤 약 2초 간격을 두고 교대로 반복합니다. 새 쇼츠·릴스 제어 안내에 동의한 뒤 각 앱의 전체 화면에서 다음을 3회, 이전을 2회 시도해 실제 영상 이동을 확인합니다. Instagram 일반 피드·스토리·메시지·댓글 입력 중에는 명령이 보내지지 않는지도 확인합니다.
1. ‘아래→위’ 모드를 선택해 아래쪽/위쪽 점을 보정하고, 연습에서 중앙 → 아래쪽(0.2–0.4초) → 빠르게 위쪽 → 중앙을 20회 반복합니다. ‘응시’ 모드도 별도 보정 후 중앙 → 위쪽(약 0.9초) → 중앙을 반복하고 인식 성공/누락을 기록합니다.
2. 일반 영상 보기처럼 눈을 움직이며 5분간 연습하고 의도하지 않은 인식을 기록합니다.
3. YouTube의 일반 영상, 홈 피드, 다른 앱에서 스와이프가 발생하지 않는지 확인합니다.
4. 쇼츠에서 중앙 → 위쪽 → 중앙을 20회 반복하고 실제 영상 전환을 확인합니다.
5. 위쪽을 계속 보거나 눈을 감거나 얼굴을 화면 밖으로 이동했을 때 반복 스와이프가 없는지 확인합니다.
6. 추적 중 화면을 끄거나 접근성을 해제하고 Android의 카메라 표시가 꺼지는지 확인합니다.

기기 모델, Android/YouTube 버전, 조명, 안경 사용 여부, 인식 성공 수와 의도하지 않은 넘김 수를 함께 기록하면 다음 조정의 근거로 사용할 수 있습니다.
